# Southern Builders – Coming Soon

A lightweight static landing page for `southerbuilders.in`.

## Files
- `index.html` – page content
- `style.css` – responsive styling
- `assets/` – PNG versions of the supplied EPS logo and 40-year service mark

## Publish with GitHub Pages
1. Create a public GitHub repository named `southerbuilders-site`.
2. Upload the contents of this folder (not the containing folder) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/southerbuilders-site/`.

## Custom domain (when ready)
In **Settings → Pages → Custom domain**, enter `southerbuilders.in` and save. Then configure the DNS records at the domain's DNS provider as instructed by GitHub Pages. Enable **Enforce HTTPS** after DNS has propagated.

No build tools or framework are required.
